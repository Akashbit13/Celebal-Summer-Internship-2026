# Week 8 - SQL for Data Analysis

## Project Overview

This project was completed as part of the **Celebal Summer Internship 2026 – Week 8 Assignment**.

The objective of this project is to generate realistic e-commerce datasets, clean the data, store it in a SQLite database, perform SQL analysis, and integrate SQL with Python.

---

## Objectives

- Generate realistic e-commerce datasets
- Clean and validate data
- Store cleaned data in SQLite
- Perform SQL analysis
- Use Window Functions
- Use Common Table Expressions (CTEs)
- Perform Cohort Analysis
- Integrate Python with SQLite
